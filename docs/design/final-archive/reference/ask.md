# Ask the Stars

**Purpose:** The contextual question-and-answer assistant, scoped to the user's structured, already-calculated chart/timing facts.

**Current authority:** Pass 3 for the core question/answer flow; Pass 4.1 for the rewarded-extension pattern; Pass 6 / 6.1 for final access and data-boundary corrections.

**Source artifacts:** `Product Design - Pass 3.dc.html`, `Product Design - Pass 4.1 - Rewarded Access.dc.html`, Pass 6 and Pass 6.1.

**Final decisions:**
- Ask answers only from structured calculated chart/timing facts, in the selected system's own terminology. It must never invent placements, houses, aspects, dashas, pillars or timing.
- The access decision resolves **before** the question is answered; an ad gate must never interrupt an answer already in progress.
- After the configured free allowance is exhausted, one completed rewarded ad may permit **one additional Ask question**.
- That rewarded grant is single-use and is not a persistent entitlement, bankable balance, coin, credit or token.
- Exact free/Premium allowance numbers remain product configuration unless separately locked later.
