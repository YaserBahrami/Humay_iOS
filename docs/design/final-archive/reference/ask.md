# Ask the Stars

**Purpose:** The contextual question-and-answer assistant, scoped to the user's own structured chart/timing facts.

**Current authority:** Pass 3 for the core question/answer flow; Pass 4.1 for the rewarded-extension access pattern, corrected by Pass 6/6.1.

**Source artifacts:** `Product Design - Pass 3.dc.html` (Ask the Stars section), `Product Design - Pass 4.1 - Rewarded Access.dc.html` (extra-question reward).

**Final decisions:**
- Ask answers only from structured, already-calculated chart/timing facts, in the selected tradition's own voice — never free-form astrology invention (Pass 6 §11).
- The access decision happens before the question is asked, never mid-answer; once the day's free question is used, an ad grants one extra question for that day only (Pass 4.1 §05).
- The Ask rewarded extension is single-use per grant — it does not persist as a standing entitlement.
