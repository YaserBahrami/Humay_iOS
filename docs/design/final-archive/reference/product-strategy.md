# Product Strategy

**Purpose:** Core strategic frame for the product — audience, value proposition, and the three-tradition (Western / Vedic / Chinese) positioning that every later pass builds on.

**Current authority:** Foundational. Not superseded by any later pass; later passes build on it and correct implementation details, not the strategy itself.

**Source artifact:** `Product Strategy.dc.html`

**Final decisions carried forward:**
- Consumer brand is **Humay**; "Eclipse" is a visual-direction codename only; "Astara" is a repo/project name only — none of these are user-facing interchangeably (see Pass 5.1, `humay-brand.md`).
- Three astrology traditions (Western, Vedic, Chinese) are read on their own terms, never scored against each other.
- No account/login is assumed; the product speaks of a **local profile**, not an account.

**Canonical screens:** none (strategy document, no UI mockups).

**Supersession notes:** None — this document is not visually superseded; product-level corrections since strategy was written are recorded in `product-completion.md` and `engineering-handoff.md`.

> Prototype astrology values shown in design artifacts are illustrative only and must not be used as engineering fixtures. Deterministic astrology engines and validated outputs are the source of truth.
