# Today & Circle

**Purpose:** The daily-reading home screen and the Circle (saved people) / compatibility surfaces.

**Current authority:** Pass 2 visual reference for Today and Circle layouts; Pass 4 for people-management detail (edit/delete/all-people list, not pictured here — see `product-completion.md`); Pass 6/6.1 govern tone rules (Roast) applied on top.

**Source artifacts:** `Product Design - Pass 2.dc.html` (Today, Circle & Today Together, compatibility report sections), `Product Design - Pass 4.dc.html` (saved-people management).

**Final decisions:**
- Today reads Normal or Roast from identical calculated facts and identical interpretive weight — Roast is tone only, never a different set of facts (Pass 6 ruling).
- "What's influencing this" discloses the astrological basis on demand; it is never forced into the primary reading.
- Today Together intensifies/softens the daily reading for a chosen person without replacing it.
