# Today & Circle

**Purpose:** The daily-reading home screen and the Circle (saved people), compatibility, and Today Together surfaces.

**Current authority:** Pass 2 remains the visual reference for Today and Circle foundations; Pass 4 covers later people-management detail; Pass 6 / 6.1 govern tone, notification, monetization and data-boundary corrections.

**Source artifacts:** `Product Design - Pass 2.dc.html`, `Product Design - Pass 4.dc.html`, Pass 6 and Pass 6.1.

**Final decisions:**
- Today reads Normal or Roast from the same calculated facts and the same underlying interpretation; Roast changes expression only.
- **Astrological basis / What's influencing this** provides the reasoning layer on demand rather than replacing the primary insight.
- Today Together is relationship-aware daily interpretation, distinct from the longer-term compatibility view.
- Roast remains in-app only and never becomes notification tone.
- Compatibility must not invent generic percentage/match scores; native named methodologies retain their own grammar where validated.
