## Product-authority adjustments

The implementation follows the task and repository product authority where the composites show older navigation labels:

- primary destinations are Today / Circle / Sky / Chart / Ask;
- Profile/Settings is auxiliary from the avatar;
- Free readings are coarse and cannot claim natal precision;
- precise screens shown in this phase are development presentation samples only;
- no provider, entitlement or purchase behavior is implied by a visual button.

## Circle and Add Person

The composites do not freeze a detailed Circle landing or Add/Manage Person family. D2 therefore implements only the approved minimal shell: two sample people, person detail, Add Person with name/date and optional unknown/approximate/exact time, and compatibility selection. Birth location is not invented because a canonical place/time-zone input design is not yet approved.

No static D2 iPad companion mockup was supplied. The implementation follows the written design authority:

- compact-width collapse to the iPhone hierarchy;
