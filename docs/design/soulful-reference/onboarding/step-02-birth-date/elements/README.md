# Birth Date Reference Elements

These SVGs preserve the small reusable visual motifs used by D1 Step 02.

They are intentionally simple, editable and repository-friendly. Their purpose is to keep later implementation and design iterations from inventing a different visual language.

## Files

- `birth-date-motif-light.svg` — calendar + sun + sparse sparkles for Light.
- `birth-date-motif-dark.svg` — calendar + crescent + sparse sparkles for Dark.
- `progress-light.svg` — compact active-step treatment on cream.
- `progress-dark.svg` — compact active-step treatment on midnight navy.

## Rules

- keep line weight thin;
- keep facial expression minimal;
- do not turn the calendar into a mascot;
- keep sparkle count sparse;
- use canonical Humay tokens;
- dark art is recolored intentionally rather than simply inverted;
- these remain design references until explicitly promoted into `Humay/Resources/Assets.xcassets/`.
