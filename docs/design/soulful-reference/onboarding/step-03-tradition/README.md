# D1 Step 03 — Tradition

Status: **APPROVED — iPhone + iPad Light/Dark, 2026-08-12**

Approved board: `tradition-cross-device-review.svg`.

## Product truth

Route: `Welcome → Birth Date → Tradition → Profile Reveal`.

Available choices remain Western, Vedic and Chinese. Selection sets the leading vocabulary/default presentation only; it does not hide the other systems, call a provider, or change entitlement. It can be changed later from Profile.

No account/login, tone/Roast, birth-time or birth-location question belongs on this step.

Canonical copy:
- `02 · Tradition`
- `Choose your starting tradition`
- `This sets the language Humay leads with. You can explore the others anytime.`
- `Your choice is a starting point, not a lock. Change it later from Profile.`
- `Continue`

## Layout

iPhone uses a single-column selection list. iPad portrait uses a bounded three-card region when labels remain readable. iPad landscape uses editorial/reassurance left and selection rows right. Compact iPad or large Dynamic Type stacks choices rather than shrinking text.

Selection is conveyed by semantic selected state, outline/tonal treatment and a check indicator; color is supplementary only. Minimum target remains 44 pt.

The W/V/C marks are reference placeholders, not required shipping icons.
