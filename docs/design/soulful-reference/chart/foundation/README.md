# D4.1 — Chart visual foundation

**Status:** REVIEW CANDIDATE — NOT APPROVED

This package establishes the first Chart visual/product foundation for:

- Chart Overview and Free entry;
- Western precision-loaded overview;
- one representative Placement Detail;
- unknown birth-time behavior;
- Free → optional Rewarded Access → Premium presentation;
- iPhone/iPad adaptive composition;
- shared Humay typography and data hierarchy.

It is visual and contract preparation only. It does not implement Chart SwiftUI, astrology providers, backend/API, rewarded ads, subscriptions, cache, natal calculations or D5 Ask.
