# Shared UI & Illustration References

These boards capture the recurring visual language extracted from D0 and used in D1.

- `ui-elements-light-dark.svg` — palette roles, typography, primary/secondary actions, chips, card language, input/state/progress and icon treatment.
- `illustration-icon-reference.svg` — simple celestial/object/icon vocabulary for the selected Humay style.

They are implementation references only. Production components should use semantic SwiftUI tokens and accessibility behavior. Production images are exported separately only when a graphic cannot be expressed cleanly as native/vector UI.

The current illustration rule is **simple, cute, editorial and sparse** — not painterly, not watercolor, not 3D, and not cartoon-heavy.
