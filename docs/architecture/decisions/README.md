# Architecture Decision Records

Use ADRs for architecture choices that future implementation sessions may otherwise reinterpret.

Each ADR should contain:

- Status
- Context
- Decision
- Consequences

Only accepted/current decisions belong in this directory. Superseded ADRs remain for history but must clearly point to their replacement.
